# Salzburg Tourist Hotels — Interactive Web Map

An interactive Web GIS application for exploring tourist hotels in Salzburg, Austria.

The application visualizes hotel locations using **Leaflet** and **OpenStreetMap**, with GeoJSON-based spatial data and marker clustering for improved visualization.

## Features

- Interactive map of hotels in Salzburg
- OpenStreetMap basemap
- GeoJSON-based hotel locations
- Marker clustering
- Hotel information popups
- Hotel name, address, coordinates, and website information
- Browser-based current location functionality
- Responsive web map interface

## Technologies

- Leaflet
- OpenStreetMap
- GeoJSON
- JavaScript
- jQuery
- Leaflet MarkerCluster
- HTML / CSS
- GitHub Pages

## Web GIS Workflow

**GeoJSON Hotel Data → JavaScript → Leaflet → Marker Clustering → Interactive Web Map**
